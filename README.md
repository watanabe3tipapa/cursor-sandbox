# cursor-sandbox

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-0.1.0-green.svg)

簡易的な「自由帳」リポジトリです。マークダウン形式のメモやノートを格納・閲覧するためのディレクトリ構成と、ローカルで動作する簡易Web版マークダウンエディタを含みます。

## 概要

- 自由なメモやノートを格納・管理するためのワークスペースとして利用します。
- マークダウンファイルをdocs/ディレクトリに置くことで閲覧・編集の対象とします。
- 簡易なWeb版エディタ（docs/index.html）を用いてローカルで編集・プレビュー・ダウンロードが可能です。

## 主なディレクトリ

- docs/
  - 自由記述のマークダウンファイルを格納してください。
  - 例: `docs/note1.md`, `docs/idea.md` など（ファイル名・内容は自由です）。
  - `docs/index.html` に簡易なWeb版マークダウンエディタが含まれます。

- memo/
  - 自由なメモやアイデアを保存するためのディレクトリです。
  - 例: `memo/2024-06-10.md`, `memo/アイデア.md` など（ファイル名・内容は自由です）。

## 簡易Web版マークダウンエディタについて

- `docs/index.html` をブラウザで開くと、ローカル環境でマークダウンの編集・プレビュー・ダウンロードが可能です。
- ファイルの直接保存やGitHubとの自動連携機能はありませんが、ファイルの読み込みとダウンロード機能が提供されています。
- `docs/` ディレクトリをGitHub Pagesなどで公開することで、オンラインでの閲覧が可能になります（公開手順はここでは記載していません）。
